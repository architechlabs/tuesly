# H12X2 warm/cool LED driver

## Observed on the user's label

- Model marking: `H12X2-15W/17W/18W/20W`.
- Marking: `Sigmesh Powered By tuya`; no separate manufacturer identified.
- Input: 110–265 V AC, 50/60 Hz.
- Output: DC 27–38 V; maximum 20 W / 480 mA.
- Printed dimming range: 5–100%.
- Output terminals: `+`, `C`, `W`, indicating a warm/cool white arrangement.
- Selectable output ratings shown on the casing. The photo does not establish
  the switch positions or actual configured current rating.

## Observed over Bluetooth

- Address: `DC:23:52:81:60:BB`.
- Advertised Mesh Proxy Service: `1828`.
- Standard GATT Mesh Proxy input/output handles: 32 / 28, confirmed through
  the ESPHome receiver at 192.168.20.181.
- Vendor service 7FDD duplicates the 2ADD/2ADE UUIDs; select the standard 1828
  characteristic objects.
- Paired in Tuya Smart. No export of its current mesh keys is available.

## Expected control path; not yet verified on this firmware

Tuya documents standard SIG lighting models for on/off (1000), brightness
(1300), and CTL temperature (1306). Those are candidates for this CCT device,
not a claim that the exact H12X2 firmware exposes them. Query and parse its
Composition Data after authenticated mesh access is established. Bind and
address each model at the actual element address returned by the node.

`lib/tuesly_mesh/sig_lighting.py` implements the standard command/status codecs
and element discovery. Version 0.2.0 connects these to an HA light controller.
Tests use synthetic standard-format packets, not driver captures.

The protocol permits temperatures 800–20000 K; this is not the lamp's physical
colour-temperature range. Query the node's CTL temperature range and verify it
against the fixture before setting HA limits. The label does not supply Kelvin
limits, company/product IDs, supported model bindings or mesh keys.

## Hardware acceptance still pending

Version 0.2.0 implements durable mesh/address/sequence ownership, journaled
PB-GATT provisioning, proxy filtering/SAR, authenticated configuration replies,
model binding and an HA light entity. It is a development release pending live
HAOS installation and commissioning/control of this specific driver. Physical
reset must intentionally replace the existing Tuya Smart pairing; use the
manufacturer's instructions rather than guessing a power-cycle sequence.
